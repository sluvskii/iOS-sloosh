# Проверка жизненного цикла «Моментов»

`bash sloosh-iOS/Tests/run-clip-playback-tests.sh` — автономные Swift-тесты
политики доступа, поколения сессии и арбитража плееров. Запускаются в macOS CI
перед сборкой iOS; не требуют симулятора, API-ключа или сети. Арбитраж тестируется
с минимальным владельцем вместо AVPlayer: эти тесты не заменяют проверку звука
и SwiftUI lifecycle на устройстве.

## Регрессии для проверки на iPhone

1. Холодный запуск → не открывать «Моменты» → дождаться загрузки ленты →
   свернуть/развернуть приложение. Нет звука моментов.
2. Открыть «Моменты» на медленной сети и сразу уйти на другую вкладку.
   После завершения резолвинга/буферизации звук не появляется.
3. Многократно переключить «Моменты» ↔ Главная/Поиск/Продолжить/Профиль.
   Моменты звучат только на своей вкладке; одновременно звучит не больше одного.
4. Из ленты открыть фильм в основном плеере; сменить качество/серию, свернуть
   и вернуть приложение. Звук только фильма. После его закрытия и окончания
   очистки момент возобновляется только при возвращении к видимой ленте.
5. Открыть детали, профиль автора, мессенджер, комментарии и отправку другу из
   ленты. Под ними нет воспроизведения момента; после закрытия — возврат
   к сохранённой позиции. Отменить интерактивный жест возврата: пока экран
   назначения открыт, момент не запускается.
6. Из профиля и чата открыть момент в отдельном полноэкранном окне.
   Он играет независимо от выбранной вкладки; после закрытия — тишина.
   Повторить по цепочке «лента → профиль → момент» и «лента → чат → момент».
7. Поставить момент на паузу вручную; открыть/закрыть комментарии, перейти
   на другую вкладку и назад, свернуть/развернуть приложение. Пауза сохраняется,
   кнопка воспроизведения после возвращения работает.
8. Во время перемотки/смены качества уйти со страницы или открыть фильм.
   Поздний seek/KVO не должен запускать старый момент либо новый момент
   вместо него. Быстро вернуться к тому же моменту — старые callbacks игнорируются.
9. Включить автопереход и уйти с ленты у конца момента. Отложенный переход
   и события изменения геометрии не должны запускать звук вне ленты.
10. Удалить текущий момент или обновить ленту и сразу уйти. Завершение запроса
    не запускает следующий момент в фоне.

## Инварианты при изменениях

- Получение данных не даёт права воспроизведения.
- `onAppear` без выбранной вкладки не даёт права воспроизведения.
- Разблокировка основного плеера сама по себе не запускает ни одной ленты.
- Каждый экземпляр ленты имеет собственный координатор; общий фокус выдаёт
  право только одному из них.
- Отмена Task недостаточна: после `await` проверяются разрешение и поколение.
- Перед положительной скоростью AVPlayer проверяется право текущего владельца.
