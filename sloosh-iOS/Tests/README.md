# Проверка жизненного цикла «Моментов»

`bash sloosh-iOS/Tests/run-clip-playback-tests.sh` — автономные Swift-тесты
политики доступа, поколения сессии и арбитража плееров. Запускаются в macOS CI
перед сборкой iOS; не требуют симулятора, API-ключа или сети. Арбитраж тестируется
с минимальным владельцем вместо AVPlayer: эти тесты не заменяют проверку звука
и SwiftUI lifecycle на устройстве. Помимо 32 базовых состояний проверяются
4096 сочетаний presentation/lifecycle: комментарии сами по себе не блокируют
видео и сохраняют поколение сессии; все остальные ограничения сохраняются.

## Регрессии для проверки на iPhone

1. Холодный запуск → не открывать «Моменты» → дождаться загрузки ленты →
   свернуть/развернуть приложение. Нет звука моментов.
2. Открыть «Моменты» на медленной сети и сразу уйти на другую вкладку.
   После завершения резолвинга/буферизации звук не появляется.
3. Многократно переключить «Моменты» ↔ Главная/Поиск/Продолжить/Профиль.
   Моменты звучат только на своей вкладке; одновременно звучит не больше одного.
4. Из ленты открыть фильм в основном плеере; сменить качество/серию, свернуть
   и вернуть приложение. Звук только фильма. После его закрытия и окончания
   очистки момент возобновляется только при возвращении к видимой ленте.
5. Открыть детали, профиль автора, мессенджер и отправку другу из ленты.
   Под ними нет воспроизведения момента; после закрытия — возврат к сохранённой
   позиции. Отменить интерактивный жест возврата: пока экран назначения открыт,
   момент не запускается.
   **Комментарии — исключение:** открыть/закрыть частичный шит комментариев
   (кнопкой и счётчиком). Видео продолжает играть над шитом с текущей позиции,
   без подмены размытым постером, пересоздания плеера или паузы. Ввод комментария
   и клавиатура не должны останавливать ролик. Из комментария перейти в профиль
   автора — воспроизведение останавливается. С открытыми комментариями свернуть
   приложение / сменить вкладку (если доступно) — звук прекращается. Повторить
   для модального момента, открытого из чата/профиля, и во время буферизации.
6. Из профиля и чата открыть момент в отдельном полноэкранном окне.
   Он играет независимо от выбранной вкладки; после закрытия — тишина.
   Повторить по цепочке «лента → профиль → момент» и «лента → чат → момент».
7. Поставить момент на паузу вручную; открыть/закрыть комментарии, перейти
   на другую вкладку и назад, свернуть/развернуть приложение. Пауза сохраняется,
   кнопка воспроизведения после возвращения работает.
8. Во время перемотки/смены качества уйти со страницы или открыть фильм.
   Поздний seek/KVO не должен запускать старый момент либо новый момент
   вместо него. Быстро вернуться к тому же моменту — старые callbacks игнорируются.
9. Включить автопереход и уйти с ленты у конца момента. Отложенный переход
   и события изменения геометрии не должны запускать звук вне ленты.
10. Удалить текущий момент или обновить ленту и сразу уйти. Завершение запроса
    не запускает следующий момент в фоне.

## Инварианты при изменениях

- Получение данных не даёт права воспроизведения.
- `onAppear` без выбранной вкладки не даёт права воспроизведения.
- Разблокировка основного плеера сама по себе не запускает ни одной ленты.
- Каждый экземпляр ленты имеет собственный координатор; общий фокус выдаёт
  право только одному из них.
- Отмена Task недостаточна: после `await` проверяются разрешение и поколение.
- Перед положительной скоростью AVPlayer проверяется право текущего владельца.

## Круглые действия на странице фильма / сериала

Ручная проверка на iPhone (не покрывается автономными Swift-тестами):

1. Вышедший фильм: под логотипом три круга «Скачать · Play · Избранное»;
   Боковые круги 52pt, Play 72pt, без подписи. Треугольник сдвинут на 2pt левее
   прежнего положения (центр без положительного offset). Повторить в landscape
   и на узком экране. Внутри треугольника виден реальный фон/изображение страницы,
   а не чёрная заливка или стекло; касание внутри выреза тоже открывает выбор.
   При нажатии прозрачность выреза сохраняется. Размер символа Play — 34pt.
   Боковые круги — плоская белая заливка 12% без стекла, размытия и обводки;
   загрузка обозначена стрелкой с нижней полочкой, а не просто стрелкой вниз.
   Навигационное сердце невышедших фильмов остаётся стеклянным и 44pt.
   Все три hero-действия используют plusLighter, как текстовые табы Главной:
   проверить тёмный и яркий цветной фон, прокрутку и смену backdrop. Круг Play
   имеет непрозрачность 85%, боковые символы — 72%, боковые заливки — 12%.
   Сравнить с предыдущей сборкой: боковые иконки чуть плотнее (65% → 72%),
   Play чуть прозрачнее (90% → 85%), боковые заливки не изменены;
   проверить читаемость сердечка, стрелки и состояний загрузки на разных фонах.
   Прозрачный вырез не должен заполняться цветом либо менять режим наложения;
   эффект не распространяется на tooltip, премьеру/таймер или навигационное стекло.
2. Play открывает прежний выбор источника/озвучки/качества, а не запускает
   произвольный поток. Для сериала проверить выбор сезона/эпизода и кнопки серий.
3. Сердце меняет состояние, показывает прежний toast, сохраняется при повторном
   открытии. В верхней панели нет дубликата. «Поделиться» доступно и после прокрутки;
   закреплённый логотип не перекрывает кнопки.
4. Начать загрузку: ожидание → кольцо прогресса → пауза → продолжение.
   Кольцо обновляется без переоткрытия страницы. Ошибка предлагает повтор;
   завершённая загрузка показывает галочку, удаление требует подтверждения.
   Отмена подтверждения сохраняет файл. Проверить фильм с externalIds вместо ids.
5. Невышедший фильм: нет Play/скачивания; осталась премьера либо прежний таймер
   Avengers. Сердце и отправка доступны сверху, в том числе после прокрутки.
6. Скелетон содержит три круга соответствующих размеров. С VoiceOver все действия
   имеют русские названия, загрузка сообщает состояние/проценты; видимого текста
   на Play нет. Повторить с увеличенным текстом и светлой системной темой:
   Details остаётся тёмным.

## Наложение текста и нейтральных иконок на меняющийся фон

`bash sloosh-iOS/Tests/run-backdrop-foreground-tests.sh` проверяет 60 вариантов
политики: светлая/тёмная тема, Increase Contrast, Reduce Transparency, сохранение
иерархии непрозрачности и обработка некорректных значений. Запускается на macOS CI,
не требует симулятора; не заменяет проверку читаемости и композитинга на iPhone.

Область применения, исключения и сценарии на устройстве:
[`docs/BACKDROP_FOREGROUND.md`](../../docs/BACKDROP_FOREGROUND.md).

После аудита иконок дополнительно проверить `info.circle` у эпизода и
неинтерактивный feedback многократной перемотки (иконка + секунды), в том числе
с Increase Contrast / Reduce Transparency. Принятые значения прозрачности/вырез плоской тройки Details не должны измениться.
Стеклянные кнопки теперь используют отдельный общий foreground-эффект (см. ниже).

## Иконки и подписи внутри стеклянных кнопок во всём приложении

`bash sloosh-iOS/Tests/run-glass-foreground-tests.sh` проверяет 64 комбинации
темы, accessibility-настроек, opt-out, disabled и инверсного цвета, отдельно
семантические tint-цвета и 4 реально отрендеренных foreground/background образца.
Проверяется, что цвет фона виден в символе, а пиксели вне символа не меняются.
Это не screenshot-тест нативного iOS Liquid Glass: его внешний вид и UIKit-табы
по-прежнему нужно проверить на iPhone по `docs/BACKDROP_FOREGROUND.md`.

## Messenger cleanup

`bash sloosh-iOS/Tests/run-messenger-search-tests.sh` runs 15 Foundation-only cases
against the shared query used by both the chat list and the new-message picker:
whitespace, Cyrillic/case-insensitive name search, tags with/without @, message
preview text, punctuation and empty-tag false positives.

Manual on-device checklist (not covered by the standalone query test):
- Moments → Chats → back returns to the same feed; no Edit/proxy/camera controls.
- Bottom tab bar stays available on the chat list (guest/authenticated). Opening an
  individual conversation hides it; returning to the list restores it. Check both
  an existing conversation and a newly selected peer from compose. Preserve the
  user's global tab-bar minimize-on-scroll preference.
- Guest can return or sign in; authenticated header has back + compose only.
- Open an existing conversation, back to list, back to Moments; all back controls
  use the same standard glass chevron, no platter morphing between unrelated actions.
- Long name, online/offline/typing status, light/dark theme, VoiceOver labels.
- Search with empty list, whitespace-only input, fast typing/clearing; opening and
  closing compose must not overwrite the main list's results or show stale results.
- Search results do not duplicate a matching existing conversation. Pull to refresh.
- Compose → choose a peer: sheet dismisses before chat is pushed; cancel changes nothing.
- Context-menu delete requires explicit confirmation explaining deletion for both
  participants; cancel leaves the chat intact. Test destructive flow only with test accounts.
- Existing send/reply/edit/reaction/retry/read/unread behavior and shared film/clip
  playback remain functional; no changes to message transport or player resolution.
